# 📝 Python To-Do List

A beginner-friendly **To-Do List application built using Python** that helps users manage their daily tasks through a simple, interactive command-line interface.

## ✨ Features

- **Add Tasks:** Add new tasks to your to-do list.
- **Delete Tasks:** Remove tasks that you no longer need.
- **Update Tasks:** Edit existing tasks.
- **View Tasks:** Display all saved tasks.
- **Exit Option:** Close the program whenever you want.
- **Error Handling:** Check whether a task exists before deleting or updating it.

## 🛠️ Technologies Used

- Python 3
- Lists
- Functions
- `while` and `for` loops
- Conditional statements (`if`, `elif`, `else`)
- User input with `input()`

## 🚀 How to Run

1. Install Python 3 on your computer.
2. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

3. Navigate to the project directory.
4. Run the Python file:

   ```bash
   python todo.py
   ```

   Replace `todo.py` with your actual Python filename if it is different.

## 📋 How to Use

1. Enter the number of tasks you want to add initially.
2. Choose an option from the menu:
   - `1` — Add a task
   - `2` — Delete a task
   - `3` — Update a task
   - `4` — View all tasks
   - `5` — Exit the program
3. Follow the prompts displayed in the terminal.

This project was created to practise fundamental Python programming concepts, including lists, loops, functions, conditional statements, and basic task management.
